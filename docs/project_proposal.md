# Project Proposal

## Name

RedMansionMind: 红楼梦哲学阐释 RAG 系统

## Goal

Build a retrieval-augmented interpretation system that connects 《红楼梦》 with Chinese philosophical traditions, especially Confucianism, Daoism, and Buddhism.

The project is designed for internship applications: it demonstrates domain-specific data construction, retrieval, grounded generation, explainable LLM application design, and a polished demo interface.

## Core User Story

A user asks:

> 贾宝玉为什么厌恶仕途经济？

The system retrieves:

- Relevant passages from 《红楼梦》
- Related concepts such as 礼, 功名, 自然, 执着, 无常
- Character/theme metadata

Then it answers with:

- A concise thesis
- Evidence from the text
- Philosophy concepts used in the interpretation
- A clear distinction between textual evidence and interpretive reasoning

## MVP Scope

- Textual QA over a curated passage set
- Perspective switch: 综合, 儒家, 道家, 佛教
- Evidence-grounded response format
- Browser UI
- Local dependency-free backend

## Portfolio Angle

This project is not a generic chatbot. Its technical claim is:

> A citation-grounded interpretive RAG system that combines literary passage retrieval and Chinese philosophy concept retrieval to support multi-perspective analysis.
